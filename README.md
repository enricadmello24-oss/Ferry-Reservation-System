
# Ferry Reservation System 🚢

A Python-based Ferry Reservation System developed collaboratively as part of a university programming assessment.

### Features
- Add, view, update, and delete maintenance records.
- Book and delete ferry tickets.
- Display ticket and maintenance records in formatted tables.
- Generate ticket IDs automatically.
- Store records using CSV files.

### Technologies Used
- Python
- CSV File Handling

### Concepts Applied
Functions, loops, conditional statements, file handling, exception handling, and lists.

### How to Run
Run `main.py` using Python 3.

```bash
python main.py
```
